# Competitor Study — mandatory, and it drives the judgement

You do **not** form a positioning opinion from intuition. You study the competitive set with live
research, build a matrix, and resolve to a **"different, not better"** wedge. This is a required step
before the resale plan and the flip verdict.

## 1. Find the competitive set (live research)
Use **WebSearch / WebFetch**:
- **G2 / Capterra** — direct rivals, their categories, review themes (what users love/hate).
- **Product Hunt / AlternativeTo** — alternatives, newer indie entrants, positioning language.
- **Rivals' pricing pages** — actual tiers, value metric, what's gated, entry price.
- **GitHub / forums** — open-source equivalents and abandoned/solo-dev tools (also feeds add-on scouting).

Pull 4–8 real competitors in the asset's niche. Prefer current data over memory — pricing moves.

## 2. Build the matrix
Fill `templates/competitor-matrix.md` — for each competitor capture: **pricing & value metric, ICP,
key features, positioning angle, and the gap** (what they ignore or do badly). Note where the target
asset sits today.

## 3. Resolve to a wedge — "different, not better"
Out-building a funded incumbent is a losing game for a sub-$5k asset. Find the wedge instead
(cross-links `growth-and-marketing.md`):
- **Vertical / ICP narrowing** — go from "everyone" to one unsexy, high-value niche (logistics,
  municipal compliance, franchise supply chain) the incumbents treat as generic.
- **Workflow over feature** — make the output *immediately actionable* via native integrations or a
  specialized UI, instead of matching the incumbent's feature list.
- **Monetization angle** — price on a different axis (usage/outcome vs per-seat) so you win the buyers
  the incumbent's model mistreats.

State the wedge as one sentence: *"For [narrow ICP], this wins by [workflow/monetization angle] that
[incumbents] structurally won't copy because [reason]."* That sentence becomes the spine of the resale
plan, the flip thesis, and the investor deck's positioning slide.

## 4. Feed it forward
- **Resale plan** (step 3): the wedge is a top value lever.
- **Flip pros/cons** (step 4): a defensible wedge is a PRO; a crowded, undifferentiable space is a CON.
- **Deck** (step 6): competitor landscape + the one-sentence wedge go on the positioning slide.

> Guardrail tie-in: if the only path you can find is "be better/cheaper than well-funded incumbents,"
> that is a 🔴 — say so. No wedge = weak flip.
